Simple, local, in control

足够强大，也足够克制

Mirroxy 专注于本机多节点管理。默认不改变 Windows 系统代理，也不会在节点故障时悄悄切换出口。

01

每个节点，一个固定入口

从 5060 起自动分配独立回环端口。应用按需选择节点，累计流量、连接数和可用性集中展示。

02

导入、订阅与路由

支持常见分享链接、订阅和 v2rayN 节点库。可全局或按节点选择绕过大陆、黑名单与全局路由。

03

本地优先，远程可控

本机面板和 AI API 免登录；远程管理独立启用并要求账号密码，可选择 HTTP、HTTPS 或自有证书。
