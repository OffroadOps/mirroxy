Mirroxy 0.8.0 — Windows x86_64 (AMD64)

下载管理：面板新增 aria2 下载页，无分类侧栏。支持新建、暂停、继续、编辑、重试、右键菜单和批量删除。删除浮窗默认不勾选删除文件；勾选时将文件移入原保存目录的 .Mirroxy-trash 回收区，可按 restore.json 手动恢复，不立即释放磁盘空间。每任务 1–16 个连接，可选直连、运行节点或自定义 HTTP 代理。完整包预置 aria2 1.37.0，任务历史加密存储。功能目前仅本机面板开放，不接管 Motrix。

首次安装：运行固定的 Mirroxy-online-setup.exe，自动读取发布清单、下载最新版 Mirroxy-windows-amd64.zip 并校验后安装。不需要随应用升级重编在线安装器。
下载失败可在安装器填写 http://127.0.0.1:10808（需已启动本地代理），留空直连，不修改系统代理。
静默安装可加 /DOWNLOADPROXY=http://127.0.0.1:10808；只有已校验完整的程序包才会开始替换，失败时保留已安装程序。历史离线 Mirroxy-windows-amd64.exe 仍可使用；ZIP 是程序载荷，不是向导安装器。
安装器默认使用 Windows 显示语言，可选择简体中文或 English。
默认安装到当前用户的 LocalAppData\Programs\Mirroxy，无需管理员权限。
本机面板：https://127.0.0.1:9527/，无需登录；安装时可选择其他空闲端口。
安装器会检测面板端口是否可用。若 9527 被占用，请关闭占用程序后重试，或选择其他端口。
静默安装可指定 /PANELPORT=9528；端口被占用时会中止安装，不会替换程序文件。
关闭网页后代理继续运行；托盘双击打开面板，右键可查看版本、选择更新或退出。

包内已经预置网络核心 A/B、路由数据和 CA 证书，不依赖 .NET。
导入分享链接或订阅后，选择节点启动；端口从 5060 起固定分配，HTTP / SOCKS5 共用。
默认“不改变系统代理”，因此可继续让 v2rayN 管理 127.0.0.1:10808。

“游戏 / 应用代理”可按正在运行的进程或完整 exe 路径分流。选中的应用全部 TCP/UDP
走绑定节点，未选应用保持原网络方式。此功能默认关闭，开启时会弹出一次 Windows UAC
以创建 Mirroxy Apps 虚拟网卡；停止功能或退出后台会撤销 TUN。
节点游戏网络能力按钮会真实穿过节点检测 TCP、UDP、IPv6 和 UDP 映射特征。

安装与升级：
下载页面最多同时运行 30 个任务、每任务最多 16 个连接。桌面窗口仅任务列表内部滚动。
右键可断点重连、打开完成文件或在资源管理器中定位；完成条目双击也会打开文件。
打开程序只在用户主动点击时执行，不会在下载完成后自动运行。执行下载程序前请核对来源。
断点重连保留已有文件、.aria2 控制文件、原链接与代理；无速度不代表完成，请勿删除断点文件。
1. 同版本安装程序重复运行时直接退出，不修改程序文件或用户数据。
2. 在线安装器比较服务端真实应用版本，拒绝重复安装/降级；使用固定 AppId 原位升级，并先请求正在运行的 Mirroxy 正常保存后退出。在线升级保留已有核心，只为首次安装补齐核心与 aria2。
3. 安装包仅保存明确选择的面板端口；保留 data、节点、凭据和累计流量，卸载也保留这些数据。
4. 0.4.x 升级到 0.5.0 时，把旧 data/settings.json 与 data/traffic.json 复制到安装目录的 data/ 后启动。
5. 首次启动会迁移节点、端口、名称和流量到加密数据库并删除旧明文文件。

从 0.5.0 起，在“更新日志”中执行在线更新。upgrade.exe 是独立更新器，必须与
Mirroxy.exe 放在同一目录；它等待旧进程退出后替换主程序和自身，启动检查失败则回滚。
不要手工运行 upgrade.exe，也不要只复制 Mirroxy.exe。

节点、订阅、远程凭据、累计流量和代理恢复信息保存在 data/Mirroxy.db 中并使用
AES-GCM 加密；data/Mirroxy.key 由当前 Windows 用户的 DPAPI 保护。请一起备份这两个文件。
运行配置位于 data/runtime，只在核心启动期间短暂存在，启动就绪后立即删除。

远程管理默认关闭；开启后必须使用设置的账号密码。本机 API 免认证。
此发布包不包含用户节点、账号密码或源代码。
