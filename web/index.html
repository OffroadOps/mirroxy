浏览器接力

等待扩展连接

安装扩展后自动连接 Mirroxy，无需复制令牌。浏览器点击下载时交给 Mirroxy 的下载管理；成功接单后才取消浏览器下载，失败会保留浏览器下载。下载管理默认在主面板内打开，也可以点其中的「独立窗口」弹出独立窗口。

下载扩展 ZIP
  1. 解压下载的 ZIP，Chrome 打开 chrome://extensions（Edge 为 edge://extensions），开启「开发者模式」，点击「加载已解压的扩展程序」并选择该目录。
  2. 保持 Mirroxy 后台运行即可，扩展会自动连接，不需要复制令牌；若未连接，点扩展设置里的「重新自动连接」。
  3. 如果自动连接失败且提示证书错误，可点击「复制扩展配置（备用）」在扩展设置中手动导入。

扩展会携带当前页面的 Referer、Cookie 和 User-Agent（只发给本机 Mirroxy），以兼容需要登录或防盗链的下载站。仍无法继续的网站可在扩展设置中排除。

扩展需要访问下载站点才能读取该站点的 Cookie；浏览器询问权限时请允许，否则需要登录的下载会失败。

自定义分流规则

每行一条规则，保存后自动应用到所有节点，无需单独切换。优先级：拦截 > 直连 > 代理 > 内置分流规则。

代理规则

命中的目标强制经当前节点代理转发。

直连规则

命中的目标直接连接，不经过代理节点。

拦截规则

最高优先级：命中的域名、关键词、正则或 IP 直接拒绝。

支持语法：域名 example.com 或 *.example.com（默认子域名匹配）、精确域名 full:host、关键词 keyword:str、正则 regexp:pat、IP/CIDR 1.2.3.4 / 10.0.0.0/8、内置组 geosite:cn / geoip:private，# 开头为注释。

Geo 规则文件

分流规则使用的 IP 归属与域名分类数据库，在这里查看状态并一键更新。

更新时从规则源下载最新文件（自动优先经运行中的节点代理），替换前校验版本与内容，完成后对应内核会短暂重启，节点与流量记录保留。

Xray 路由数据库（网络核心 A）

进入本页自动查询规则源最新版本。

sing-box 规则集（网络核心 B）

网络核心 B 的分流规则使用这些本地规则集；缺失或过期会直接影响绕过大陆与黑名单模式的准确性。

HTTPS 证书（可选）

不填写时自动生成自签证书，首次远程打开会提示证书未受信任。公网域名建议填写对应的正式证书。更换协议或证书时请同时选用新管理端口，保存后访问新地址。

开启后通过所选协议和此设备的 IP:端口访问。此处不会自动修改防火墙或路由器；代理端口仍仅监听本机。Windows 的远程设置只能在本机修改；Linux 管理员可在面板修改。
